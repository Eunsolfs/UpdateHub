根据你的需求选择合适的部署方式：

### 🚀 推荐方式：脚本一键部署 ⭐

**适合人群**：所有用户，特别是新手

**特点**：
- ✅ 最简单、最快捷

- ✅ 适合了解内部原理

**时间**：10-15分钟

## 📋 部署前准备

无论选择哪种部署方式，都需要准备：

### 硬件要求
- **CPU**: 2核心以上
- **内存**: 2GB以上（推荐4GB）
- **磁盘**: 20GB以上可用空间

### 软件要求
- **操作系统**: Linux (Ubuntu 20.04+, CentOS 7+, Debian 10+)
- **Docker**: 20.10+
- **Docker Compose**: 1.29+
- **网络**: 能访问 GitHub Container Registry

### 账号要求
- GitHub 账号（用于访问 GitHub Container Registry）
- 如果使用私有镜像，需要配置访问权限

## 🔧 卸载 UpdateHub

### 脚本一键卸载

如果使用脚本一键部署，可以使用卸载脚本：

```bash
cd /opt/UpdateHub/scripts
./uninstall.sh
```

卸载脚本会提供选项：
- 保留数据，只删除服务
- 清除所有数据和服务
- 选择性清理

### 手动卸载

其他部署方式需要手动清理，请参考对应部署文档中的卸载章节。

## 💡 常见问题

### Q: 哪种部署方式最稳定？
A: 脚本一键部署最稳定，因为经过了大量测试。

### Q: 可以从一种部署方式切换到另一种吗？
A: 可以，但建议先备份数据，然后卸载当前部署，再使用新方式部署。

### Q: 部署失败怎么办？
A: 首先检查环境是否满足要求，然后查看日志文件，最后查阅故障排除文档。

### Q: 可以在 Windows 上部署吗？
A: 主要支持 Linux，Windows 建议使用 WSL2 或虚拟机。
